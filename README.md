## 三、核心实现原理深度解析

### 3.1 外弹道与两级固体火箭动力学模型

桌面端（`rust/src/core.rs`）与网页端（`web/public/index.html` 内的 `WT` 物理模块）实现了完全同构的二维铅垂面（水平射程 $s$ - 绝对海拔 $y$）质点气动与火箭推进动力学方程：

1. **国际标准大气（ISA）密度与当地声速模型**
   - 海拔 $y$（单位：$\text{m}$）处的空气密度 $\rho(y)$ 与当地声速 $a(y)$ 按国际标准大气对流层公式计算：
     $$\rho(y) = 1.225 \cdot (1 - 2.25577 \times 10^{-5}\, y)^{4.2559}, \qquad a(y) = 340.29 \sqrt{\max(0.5,\; 1 - 2.25577 \times 10^{-5}\max(0, y))}$$
   - 为避免在数万步积分循环中频繁调用高开销的浮点幂函数 `powf(f, 4.2559)`，在常规作战海拔区间内采用预展开的泰勒-霍纳（Horner）多项式逼近，相对误差小于 $10^{-6}$ 且吞吐提升数倍。

2. **常规无动力弹丸气动阻力方程**
   - 截面积 $S = \frac{\pi d^2}{4}$，单位质量阻力系数 $k = \frac{C_x S}{2 m}$，速度矢量 $\vec{v} = (v_x, v_y)$，重力加速度 $g = 9.81\text{ m/s}^2$：
     $$a_x = -k\,\rho(y)\,|\vec{v}|\,v_x, \qquad a_y = -g - k\,\rho(y)\,|\vec{v}|\,v_y$$
   - **缺失风阻回退估算（`cxEst`）**：部分老式弹药在拆包文件中未显式声明 `Cx`（游戏引擎使用内部默认表），`localize_data.py` 会按“精确同弹种 `bulletType` 中位数 → 同大类弹种前缀中位数 → 全局中位数”三级统计池自动填充，并在界面上显式标注 **「估算风阻」** 提示误差边界。

3. **两级固体火箭发动机、导轨约束、马赫波阻与自毁引信模型**
   针对机载非制导火箭弹与陆战多管火箭炮，完整建模了 5 个关键物理阶段：
   - **两级时变质量与推力函数 $(m(t), F_{\text{thrust}}(t))$**：
     - 点火延迟期 $t < t_{\text{delay}}$：质量保持初重 $m_0$，推力为 $0$；
     - 一级助推燃烧期 $t \in [t_{\text{delay}},\, t_0]$：推力恒为 `force0`，质量从 $m_0$ 线性递减至一级燃尽质量 `mEnd0`（精确反映推进剂消耗带来的推重比攀升）；
     - 二级续航燃烧期 $t \in (t_0,\, t_1]$（若存在二级发动机 `tFire1 > 0`）：推力切换为 `force1`，质量从 `mEnd0` 线性递减至最终空重 `mEnd1`；
     - 关机惯性滑翔期 $t > t_1$：推力归零，弹体以空重 `mEnd1` 进入纯气动阻力抛物滑翔。
   - **直升机平飞初速矢量合成与 2 米发射导轨约束（`on_rail`）**：
     - 当直升机以平飞空速 $v_{\text{air}}$ 投射火箭弹时，初始速度矢量为 $(v_{\text{air}} + v_{\text{start}}\cos\theta,\; v_{\text{start}}\sin\theta)$；
     - 若弹药管内初速 $v_{\text{start}} < 5\text{ m/s}$（典型挂架/火箭巢静止点火弹药），前 $2.0\text{ m}$ 管内行程受发射管仰角 $\theta_0$ 刚性约束，仅沿发射管轴向加速（扣除重力在管轴方向的分量与迎风阻力），离轨后再转入自由飞行并按气动风标效应使弹轴角 $\theta$ 渐近追随空速矢量方向 $\operatorname{atan2}(v_y, v_x)$。
   - **跨音速马赫数阻力曲线（`CxK` / `rocket_cd0(Mach)`）**：
     - 凡拆包中采用马赫数阻力乘子 `CxK` 的火箭弹，瞬时阻力系数按当地马赫数 $M = |\vec{v}| / a(y)$ 动态计算：亚音速段（$M \le 0.8$）取基准值 $0.29$；跨音速激波段（$0.8 < M \le 1.1$）经三次 Hermite 曲线平滑爬升至峰值 $0.68$；超音速段（$M > 1.1$）按 $0.26 + \frac{0.42}{1 + 0.55(M - 1.1)}$ 随马赫数升高而回落。
   - **定时 / 定距半空自爆引信（`timeLife` / `maxDistance`）**：
     - 每一步积分实时检测飞行时间 $t \ge t_{\text{life}}$（如俄系 S-8KO 在 `15.0 s` 凌空自爆）或斜距 $\sqrt{s^2 + (y - y_0)^2} \ge D_{\max}$，一旦触发立即截断弹道并记录自毁原因（`time` / `dist`），避免给出游戏内实际会在半空自爆的虚假超距解。
   - **二阶 Heun 预测-校正积分器（RK2）**：主动燃烧段采用精细时间步长 $\Delta t = 0.004\text{ s}$，关机滑翔段自适应切换步长并省去零推力三角函数运算。

### 3.2 零内存分配 `TrajFan` 毫秒级实时射表解算器

在武装直升机模式下，单次移动机位或调整悬停高度，需要同时解算：**主目标 B 精确仰角、本局全部战区（A/B/C）与双方陆战出生点多目标射表、1km~8km 距离梯度射表、`±0.5°` 仰角齐射散布跨度、最大自毁射程包络圈，以及 3D 瞄准镜动态距离分划**。若对每个目标和距离刻度独立运行二分打靶法，单次更新需执行数千次完整火箭积分，导致严重卡顿。

为此，双端核心均设计了**零堆内存分配的二维仰角-距离预计算扇面 `TrajFan`（`build_traj_fan` / `buildTrajFan`）**：
1. 在当前发射海拔 $y_0$ 与平飞空速 $v_{\text{air}}$ 下，以 $0.5^\circ$ 为步长一次性扫过俯仰射界 $[p_{\min}, p_{\max}]$，在单块连续平坦数组（`Vec<f32>` / `Float32Array`）中按固定水平步长 $\Delta s = 20\text{ m}$ 记录高度差矩阵 $Y[k, i]$、飞行时间矩阵 $T[k, i]$ 与自毁截断状态；
2. 任意目标 $(d, \Delta y)$ 的高低双解直接在该二维网格上沿距离轴与仰角轴做双线性过零插值求根（主目标 A→B 再辅以 20 步局部二分精修，角度误差 $< 0.003^\circ$）；
3. 齐射落点跨度 `span_05`、距离标尺与极限自毁包络 `envelope` 全部通过查表在微秒内完成。
4. **实测耗时**：卡-52 挂载 S-8KO 火箭弹时，Rust 桌面端完成全套三级射表 + 弹道解算仅需 **`~13.8 ms`**，Web 端仅需 **`~5.7 ms`**；且桌面端将文本射表与最大射程圈缓存于 `Viewer::update_aim`，在鼠标移动、2D 漫游与 3D 旋转拖拽期间物理重算耗时严格为 **`0.00 ms`**。

### 3.3 双层地形融合（1m 级核心战区 `HM2` + 20km 外圈空域 `LandMesh`）

《战争雷霆》陆战地图在客户端 `levels/avg_*.bin` 中原本就由两套精度不同的地形组成：中心交战区是高分辨率 `HM2` 高度图（通常 $2\sim 4\text{ km}$ 见方，格距 $1\sim 4\text{ m}$），而直升机停机坪往往位于中心战区外侧 $4\sim 10\text{ km}$ 处，属于外圈 `LandMesh` 航空地形。

本项目通过双层地形架构同时兼顾了**核心战区的米级掩体精度**与**外圈 20km 空域的山体遮挡真实感**：
- **内圈核心地形（`t` / `HM2`）**：保留完整分辨率，表面高程查询采用与 Dagor 引擎一致的**中心点四三角剖分插值（Diamond 4-Triangle Interpolation）**，确保坦克底盘贴合斜坡法线（`hull_pose`）与棱线遮挡判定分毫不差。
- **外圈空域地形（`t_air` / `LandMesh`）**：由 `extractor/objects/src/bin/airspace.rs` 提取 `LandMesh::tracer_mesh()` 射线碰撞网格，覆盖全部四座停机坪外扩 `2.4 km` 视野（跨度 `13.3~25.6 km`），光栅化为 `1024×1024`（格距 `13~26 m`）16 位高度图，并使用 `GroundBaker` 混合 `LandClass` 材质权重烘焙配套的 `1024×1024` 卫星地表贴图。
- **内外圈零接缝与防重影裁剪**：
  1. 在导出外圈高度图时，凡落入内圈 `HM2` 矩形内的格点直接覆写为精确双线性采样的 `HM2` 高度，使内外圈边界高程差严格为 `0.00 m`；
  2. 在 3D GPU 渲染器（`view3d.wgsl` 与 WebGL2 着色器）中，内外两套地形共用同一套四叉树视锥裁剪 + 屏幕误差 LOD 网格（每个块为 $64\times 64$ 格并带一圈向下折弯的防裂裙边 Skirt），外圈地形与外圈水面片元着色器通过 `uClipInner` 精确 `discard` 掉内圈矩形区域，彻底消除双层网格重叠引起的深度闪烁（Z-fighting）。

### 3.4 全图 224 座直升机出生点“去土包”高程校准与 1m 级 3D 原版机场重建

#### （1）为什么直接读取战雷任务文件会出现“圆锥土包”或“地下深坑”？
对全部 **56 张地图共 224 座直升机停机坪**做跨数据源审计后证实：战雷 `.blkx` 任务文件中的 `objectGroups`（`dynHelipad_*`）虽然水平坐标 $(x, z)$ 与水平朝向矩阵准确无误，但其中的高度分量 **`tm[3][1]`（即 $y$ 值）大量保留了官方关卡编辑器复制模板时的过期高度**：
- 224 座停机坪中有 **128 座**与真实 `LandMesh` 地面高度相差超过 `5 m`，**63 座**相差超过 `15 m`；
- 典型极端案例如 **咸海（`avg_aral_sea`）**：任务模板残留着 `166.6 m ~ 234.9 m` 的高度，而咸海干涸湖盆真实地面仅为 `10.8 m ~ 155.8 m`（悬空高达 **`+95.6 m ~ +217.3 m`**）；又如 **伊比利亚古堡（`avg_iberian_castle`）**直接复用了废弃工厂模板的 `88.7 m`，而实际山脊海拔为 `154.2 m`（陷入地下 **`-65.5 m`**）。
- 在 Dagor 引擎内部，所有 `gamedata/objectgroups/dynhelipad_*.blk` 均声明为 `className:t="composit"`，运行时会自动忽略 `tm[3][1]`，直接贴合到 `LandMesh` 真实地表并将矩形机场区域压平。若简单将 `.blkx` 里的错误 $y$ 值印到外圈粗糙网格上，就会形成突兀的圆锥“土包”。

#### （2）真实地表重采样与余弦护坡平整
`extractor/objects/src/bin/airspace.rs` 彻底弃用了 `.blkx` 中的错误 `tm[3][1]`：
- 对外圈停机坪（222 座）：先在未修改的自然 `LandMesh` 网格上，沿每座停机坪自身的局部正交基 $(u_x, u_z)$ 对停机坪核心区做 `17×17` 密集双线性采样，取其中位数作为真实海拔 $y_{\text{true}}$（有水面的地图自动保底 $\ge y_{\text{water}} + 1.6\text{ m}$，防止北极圈等海冰机场低于水面）；随后将外圈高度图在旋转矩形坪面内平整至 $y_{\text{true}} - 0.25\text{ m}$，并在外围 `85 m` 宽度内按余弦权重 $w = \frac{1}{2}(1 + \cos(\pi d / 85))$ 自然融入周围山坡。
- 对位于内圈 `HM2` 内的近距停机坪（如叙利亚 `avg_syria` 近距坪）：由于不破坏原版 `HM2` 地形数据，取坪面覆盖区 `HM2` 最高点 $+0.06\text{ m}$ 作为台面标高，确保下方地形零穿模。

#### （3）1 米级 3D/2D 原版机场预制体与 GPU 硬件实例化
`extractor/objects/src/bin/helipads.rs` 为全部 6 套战雷原版机场预制体生成共享模型包 `helipads.js`（共 **55 个 `WTVO v3` 量化三维网格**，压缩后仅约 `236 KB`）：
1. **程序化 1 米精度机场底盘网格（`pad_deck_*`）**：包含平整碎石/混凝土/压实雪地台面、混凝土路缘石、**四周向外延伸 `32 m` 并下探 `-24 m` 的三维斜坡护堤裙边**（即使建在陡峭山腰上也能与山体严丝合缝，绝无悬空裂缝）、带端头斑马线与中心虚线的主起降跑道、黄色滑行引导线，以及主跑道中心 `[H]` 指挥坪和全部 **16 个按原版 `spawn:p3` 坐标精确摆放的独立 `[H]` 出生机位**（起飞箭头统一指向 `-tm[0]` 即陆战交战区方向）。
2. **49 种战雷原版 `RiModel` 机场建筑与勤务车辆**：塔台、机库、营房、军用帐篷、储油罐、集装箱与美/苏勤务卡车全部按 `.blk` 原始局部变换矩阵摆放。
3. **世界矩阵合成与厘米级高程判定**：加载任意地图时，将预制体局部实例矩阵与停机坪水平旋转平移矩阵合成 $M_{\text{world}} = M_{\text{local}} \cdot M_{\text{pad}}$，按模型 ID 合并批次提交 `wgpu` / `WebGL2` 硬件实例化管线（`draw_indexed` / `drawElementsInstanced`）；同时在 `LoadedMap::stand`、`surf_at` 与前端 `WT.withPads` 中同步计算台面及 `32 m` 护坡斜面的解析高度：
   $$y_{\text{pad}}(x, z) = \max\left(y_{\text{terrain}}(x, z),\; y_{\text{true}} - \frac{d_{\text{rect}}}{32.0}\times 24.0\right) \quad (0 \le d_{\text{rect}} \le 32\text{ m})$$
   从而保证 3D 鼠标射线拾取（Ray-picking）、视线遮挡、弹道落点与画面看到的机场三维网格在任意位置均精确到厘米级一致。

### 3.5 建筑碰撞体、植被树冠光栅化与全图多线程空间扫描算法

1. **核心区建筑与植被双层高度包络（`extractor/objects/src/main.rs`）**
   - **刚体建筑与巨石碰撞层（`roof`）**：提取 `levels/*.bin` 中所有具备子弹追踪属性（`traceable()`）的 `COLLISION` 节点，仅当世界包围盒高度 $\ge 2.5\text{ m}$ 且水平投影面积 $\ge 6.0\text{ m}^2$ 时（自动忽略低矮木栅栏、路牌与鹅卵石），将其碰撞三角面光栅化至与 `HM2` 同分辨率的 `roof` 网格（高度量化精度 `0.05 m`）。
   - **植被树冠层（`veg`）**：识别带有 `impostor` 或朝向叶片材质（`is_facing_leaves`）的树木灌木，按模型名称自动归类为阔叶树、针叶树、棕榈树、灌木 4 种三维代理树冠，同时将其树冠圆盘包络写入 `veg` 网格。用户可独立开关「树木阻挡视线」与「树木引爆/阻挡炮弹」（适配破甲弹 HEATFS 与敏感引信榴弹）。

2. **多线程极坐标射线扫描（`sweep_reach` / `sweep_hit` / `sweep_view`）**
   - 将周向划分为 $N_{\text{az}} \in \{360, 720, 1440\}$ 条方位角射线，桌面端通过 `rayon` 并行迭代器、网页端通过多 `Web Worker` 分扇区并行计算：
     - **A 点火力覆盖（`sweep_reach`）**：预计算弹道高度表 `Table`，沿每条射线先提取地形/屋顶包络上界 `ceil`，对整段高于 `ceil` 的高抛弹道弧段直接从弹道顶点 `apex` 二分跳越至下降段，跳过 80% 以上无效步进；
     - **可打到 B 的阵地（`sweep_hit`）**：从目标 B 反向发射射线寻找潜在开火点 P，解出所需仰角后回溯验证全路径无山体遮挡，按位或标记 `1 = 低伸直射可达（绿）`、`2 = 高抛跨山曲射可达（橙）`、`3 = 直射与曲射皆可（蓝）`；
     - **A 点视野通视（`sweep_view`）**：沿射线维护最大仰角斜率地平线 `maxS = max((y - y_eye) / d)`，不仅标出通视区，还在视线首次被截断的棱线像素处读取 `srcAt` 区分染色（山体地形 / 建筑巨石 / 树木灌木）。

### 3.6 数据压缩编码与双端工程架构（`WTVPACK2` 单文件自包含 & 零依赖 Web 全栈）

1. **16 位高度图无损差分预测编码（`.hpred`）与 `WTVO v3` 模型量化**
   - 原始 16 位高度图相邻格点高度极度相关，直接压缩率有限。`store.rs::predict` 与 `pack_airspace.py` 对每行采用**二维线性梯度预测残差编码**：
     $$r_{x,y} = \bigl(h_{x,y} - (h_{x-1,y} + h_{x,y-1} - h_{x-1,y-1})\bigr) \bmod 65536$$
     将平滑山坡转化为接近全零的窄分布残差，再配合 XZ（预设 6/9）或 Gzip 压缩，体积缩减约 60%~75% 且 **100% 比特级无损还原**。
   - `WTVO v3` 将静态建筑模型顶点从 `3 × f32`（12 字节）量化为模型局部包围盒内的 `3 × u16`（6 字节），法线压缩为 `snorm8x4`（4 字节），兼顾极小体积与 GPU 直接上传效率。

2. **Windows 单文件自包含打包协议（`WTVPACK2`）**
   - `extractor/repack_cn.py` 将编译好的纯原生 `wtv.exe`（Rust + `gpui` 界面 + `wgpu` 4× MSAA 离屏三维管线）作为文件头，在其尾部依次追加全部 **566 个**独立 XZ 压缩资源块（索引、56 张内圈地图/贴图/碰撞体、112 个外圈空域地形/卫星图、`helipads.js` 机场模型库及坦克三维白模），最后写入 JSON 偏移目录表与 24 字节定长尾标：
     ```text
     [ 原生 PE 可执行文件 wtv.exe ]
     [ XZ 资源块 #0 ][ XZ 资源块 #1 ] ... [ XZ 资源块 #565 ]
     [ UTF-8 JSON 目录: [["index.js", offset, len, 1], ...] ]
     [ u64_le index_offset (8B) ][ u64_le index_length (8B) ][ Magic "WTVPACK2" (8B) ]
     ```
   - 程序启动时读取文件末尾 24 字节定位目录表，按需随机寻址（`SeekFrom::Start(offset)`）在内存中流式解压目标地图，**不在磁盘释放任何临时文件夹**，真正实现单 `.exe` 拷走即用。

3. **零第三方依赖的在线 Web 全栈架构（`web/`）**
   - **后端（`web/server.py`）**：纯 Python 3.10+ 标准库实现（零 `pip` 依赖），采用 `ThreadingHTTPServer` + `SQLite3`（开启 `WAL` 并发日志与 `busy_timeout`）：
     - **账号安全**：密码经 `hashlib.scrypt`（$N=16384, r=8, p=1$，独立 16 字节随机盐）哈希存储；登录态采用 SHA-256 摘要入库的 `HttpOnly` + `SameSite=Lax`（HTTPS 下自动附加 `Secure`）Cookie；全部写接口强制校验 `X-Requested-With: XMLHttpRequest` 防御跨站请求伪造（CSRF）。
     - **邀请码准入与管理后台**：注册新账号必须填写有效邀请码（在 SQLite `BEGIN IMMEDIATE` 事务内原子扣减可用次数）；管理员可在前端可视化后台一键创建单次/多次/无限次邀请码、启停或删除邀请码、重置用户密码及管理账号。
     - **30 槽个人云存档**：每位用户独立拥有最多 30 个参数预设槽位，完整保存地图、模式、任务、载具、弹种、A/B 坐标、直升机悬停高度/平飞空速、钉选目标点、红区开关以及 2D/3D 相机姿态。
     - **预压缩静态直出**：`web/extract_web_data.py` 将数据包预先转为 `.gz` 文件，后端检测浏览器 `Accept-Encoding: gzip` 后直接零拷贝返回预压缩字节流，大幅降低服务器 CPU 占用与首屏加载耗时。
   - **前端与移动端触屏适配（`web/public/index.html`）**：原生 ES2022 + Canvas2D + WebGL2（`#version 300 es`）单页应用，内置可左滑收起的抽屉式侧栏、单指漫游/点选、长按震动放 B 点、双指捏合缩放、虚拟 `WASD + Q/E` 驾驶/升降方向盘与瞄准镜触控倍率条。

## 五、快速上手与操作指南

### 1. 陆战火炮与多管火箭炮模式
1. 在左侧栏选择**作战地图**、**载具分类（陆战）**、**载具型号**与**选用弹药**（支持直接输入如 `咸海`、`废弃工厂`、`安德柳沙`、`喀秋莎`、`突击虎`、`99a`、`2s38` 实时筛选）。
2. 在地图上**左键点击**放置己方开火点 **A**，**右键点击**（手机端单指长按、切换顶部 `单点：放 B`，或点击侧栏 **「反制敌方停机坪」** 按钮）放置目标点 **B**（支持直接设在外圈直升机停机坪及任意 `[H]` 出生机位）。
3. 左侧面板实时给出水平距离、斜距、高差、方位角、视线遮挡状态，以及**低伸弹道（直射）**与**高抛弹道（曲射）**两组精确仰角、密位抬高量、飞行时间与落点存速。

### 2. 武装直升机火箭弹射表模式
1. 点击载具分类 **「直升机 (114)」**，选择武直机型与火箭弹（如卡-52 挂载 `S-8KO` 或 `S-13OF`、直-10 挂载 `90-1 型`、AH-64 挂载 `Hydra-70`）。
2. 地图自动解锁 **20 km 外圈空域**并显示双方 4 座高精度停机坪。点击 **`1队近H1` / `1队远H2` / `2队近H1` / `2队远H2`** 可一键落位停机坪跑道（2D 放大后也可直接点击机场内任意一个独立 `[H]` 机位吸附落点）。
3. 调节 **「悬停离地高度 AGL (m)」** 与 **「机身平飞空速 (km/h)」**（`0` 为悬停，前飞时自动合成机身初速修正仰角）。
4. 射表面板直接输出与战雷武直 HUD 同款的 **「罗盘方位角 (°) + 机头俯仰角 (°)」**，下方同步列出本局全部占领战区（点击任意一行可直接将其设为 B 点）及距离梯度速查表。
